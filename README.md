# AI Document Intelligence

AI-powered financial document extraction and validation platform.

## Supported Documents

- Invoice
- Balance Sheet
- Profit & Loss
- Cash Flow Statement

## Features

- PDF/JPG/PNG upload
- File validation
- Native PDF text extraction
- OCR for scanned documents
- Structured financial data extraction
- Deterministic financial validation
- SQLite persistence
- REST API
- Swagger/OpenAPI documentation
- Dashboard
- Processing history
- PASS / FAIL / NOT_APPLICABLE validation
